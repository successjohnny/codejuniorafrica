LESSON 1

What makes a website?

A website is a page you can open in a web browser. Two important building blocks are:

🧱

HTML

HTML gives a webpage its structure, such as headings, paragraphs, and images.

🎨

CSS

CSS controls how a webpage looks, including colours, fonts, spacing, and layout.

Think of a house!

HTML is like the walls and rooms. CSS is like the paint, decorations, and style.
